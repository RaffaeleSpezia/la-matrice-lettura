Verifica degli EPUB · 1.1.6

Ogni impronta SHA-256 identifica tutti i byte del file EPUB. Il messaggio pubblico Hedera registra quell’impronta a un timestamp di consenso. Non certifica la verità del contenuto né garantisce la disponibilità futura.

Each SHA-256 identifies the complete EPUB file. Compare it with epub_sha256 in the public Hedera message. No account or private key is required.

Cada SHA-256 identifica el archivo EPUB completo. Compárelo con epub_sha256 en el mensaje público de Hedera. No se necesitan cuentas ni claves privadas.

3f996574f3ae7ba0e602677ae27a6ea3d357c873f933104d7b2ec07f18c5e0b9

Hedera mainnet · topic 0.0.10926025 · messaggio 20
Consensus timestamp: 1793381996.230717826

Messaggio originale dal mirror pubblico · Busta JSON leggibile · Manifesto

  1. Scarica l’EPUB. Calcola SHA-256: Linux sha256sum la-matrice-1.1.6.epub; macOS shasum -a 256 la-matrice-1.1.6.epub; PowerShell Get-FileHash la-matrice-1.1.6.epub -Algorithm SHA256.
  2. Apri il messaggio originale del mirror, decodifica il campo message da Base64 a JSON e confronta epub_sha256, versione e lingua. La copia JSON qui accanto è una comodità: il riferimento indipendente è il mirror pubblico.
  3. In alternativa scarica verifica_epub.py, leggine il codice ed esegui:
    python3 verifica_epub.py --epub la-matrice-1.1.6.epub --versione 1.1.6 --lingua it --sequenza 20
    Usa solo Python standard, scarica il messaggio dal mirror e confronta l’impronta: nessuna credenziale.
